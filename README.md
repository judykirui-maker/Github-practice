GitHub Basics – My Learning Journey

Introduction

This repository documents my learning journey in GitHub. I learned how to use GitHub to store, manage, organize, and share my project files.

What I Learned

How to create a GitHub account and repository.

How to create files and folders.

How to upload files from my computer to GitHub.

How to edit and rename files.

How to organize project folders.

How to write and update a README.md file.

How to make commits and write meaningful commit messages.

How to track changes in my repository.

How to navigate the GitHub interface.

Important GitHub Terms

Repository: A place where project files and their history are stored.

Commit: A saved change made to a repository.

README.md: A document that explains what a project is about.

Branch: A separate line of development where changes can be made.

Push: Sending local commits to a remote repository.

Pull: Bringing changes from a remote repository into a local copy.

Challenges I Experienced

At first, I found it difficult to organize files and folders, upload assignments, and understand where different files belonged. I also experienced some confusion when editing and renaming files.

Through practice, I became more confident in navigating GitHub and managing my project files.

What I Gained

I learned that GitHub is not only a place to store code but also a useful tool for collaboration, tracking progress, and managing software projects.

Conclusion

My GitHub learning journey has helped me become more comfortable with managing repositories, organizing files, and documenting my work. I look forward to improving my skills through more practice.
