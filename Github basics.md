GitHub Basics
What Is Git?
Git is a version control system that tracks changes made to files over time.
What Is GitHub?
GitHub is an online platform for hosting Git repositories and collaborating on projects.
Local and Remote Repositories
Local repository: A repository stored on my computer.
Remote repository: A repository hosted online on GitHub.
Git Commands Practised
Command	Purpose
git init	Initialises a local Git repository.
git clone	Copies a remote repository to my computer.
git status	Shows the current state of my working files.
git add	Stages changes for a commit.
git commit -m "message"	Records staged changes locally.
git remote -v	Displays remote repository URLs.
git push	Uploads committed changes to a remote repository.
git pull	Fetches and integrates remote changes. What I Have Learned
